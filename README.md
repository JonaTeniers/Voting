# Voting

Eenvoudige webapp voor een klassikale Eurovision-puntenronde.

## Starten

Open `index.html` in je browser.

## Werking

1. In **Namen ingeven** voeg je leerlingen toe (één per regel).
2. Namen worden alfabetisch gezet.
3. In **Publiek** start de beurtvolgorde onderaan de alfabetische lijst.
4. Publiekspunten tellen meteen mee in het totaal.
5. Pas daarna gebruik je **Jury** om je eigen punten toe te voegen.
6. Het klassement herschikt automatisch op totaalscore.
